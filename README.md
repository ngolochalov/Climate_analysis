# Климатические факторы риска токосъёма — СЛД Кандалакша

Исследовательская работа УрГУПС: анализ влияния климатических и погодных факторов
района эксплуатации сервисного локомотивного депо (СЛД) Кандалакша на условия
токосъёма и потенциальный износ вставок токоприёмников.

Полный контекст задачи, принятые архитектурные решения и план работ — в
[`PROJECT_BRIEF.md`](PROJECT_BRIEF.md). Исходное техническое задание —
[`ПРОЕКТ ЗАДАНИЯ для УрГУПС.docx`](ПРОЕКТ%20ЗАДАНИЯ%20для%20УрГУПС.docx).

## Структура проекта

```
ingest/        # выгрузка данных из источников (ERA5 / Open-Meteo, станция rp5/meteo.ru)
db/            # ORM-модели SQLAlchemy, схема БД, загрузка
process/       # очистка, восполнение пропусков, производные параметры, флаги явлений
analysis/      # движок критериев риска и детектор критических периодов
viz/           # графики, тепловые карты, временные шкалы
data/raw/      # сырые выгрузки источников (кэш, в .gitignore)
data/clean/    # обработанные данные и итоговая SQLite БД
config.yaml    # координаты станции, период выгрузки, пороги риска
```

## Окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Источники данных

- **Станция Кандалакша (ВМО 22217)** — срочные наблюдения через rp5.ru / meteo.ru
  (ВНИИГМИ-МЦД). Основной источник, в т.ч. ради кодов текущей погоды (гололёд,
  изморозь, мокрый снег).
- **ERA5 (Open-Meteo Historical Weather API)** — почасовой реанализ без пропусков,
  используется для восполнения пропусков станции и кросс-проверки.

Каждая запись в БД помечается полем `source` (`station` / `era5` / `filled`).
